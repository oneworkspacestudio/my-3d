# Foundation audit, 23 October 2026

The official [TweakCAD open-source page](https://tweakcad.com/open-source) advertises AGPL-3.0, OCCT, feature history, offline operation, `.cadjson` and STEP/STL/3MF. Its linked `https://github.com/HumanHub/TweakCAD` returned HTTP 404 through both GitHub API and browser retrieval. No source, tests, editor API, solver, licence file or file format could be audited. This repository is new; it contains no TweakCAD code and makes no claim of `.cadjson` compatibility. The upstream marketing claims are unverified, not implemented capabilities.

Alternative inspected: Replicad 1.1.0, MIT, published source commit `e4b05f67dc4e2393a876ce8c5064a9c93db05bf1`, with `replicad-opencascadejs` 1.1.0. Its checked npm declarations/implementation expose `drawRectangle`, `drawEllipse`, `sketchOnPlane`, `extrude`, `fuse`, `cut`, `fillet`, `mesh`, `serialize`, `deserializeShape`, `blobSTEP`, `blobSTL`, `measureVolume` and STEP import. The exact B-Rep source is rebuilt in a bounded worker; Three.js only displays its tessellation. It does not supply a general sketch constraint solver. My 3D implements dimensioned rectangle/circle parameters and closed polylines with explicit limits.

Source hierarchy: primitive or sketch parameters → editable group/boolean source children → OpenCascade B-Rep → display/export tessellation. Export STL/3MF fuse the visible CAD solids. Hole tools must first be applied with Group. Imported triangle meshes remain meshes, with clear operation limits. A failed CAD recomputation retains editable state and reports an error; export of stale geometry is refused. Worker operations have a 60-second deadline and a Cancel button; no hard WASM memory cap is claimed.

The single-threaded WASM is unmodified from the pinned npm distribution. Its source builder is [Replicad](https://github.com/sgenoud/replicad/tree/e4b05f67dc4e2393a876ce8c5064a9c93db05bf1/packages/replicad-opencascadejs); it references [taucad/opencascade.js](https://github.com/taucad/opencascade.js/tree/ebd263f15337b440b391492af073662707e86482). That builder's DEPS.json pins OCCT `b8f597c677811d1f9f4d8a97f5ae2825c0353a42` (V8_0_1), RapidJSON `24b5e7a8b27f42fa16b96fc70aade9106cf7102f`, FreeType `de8b92dd7ec634e9e2b25ef534c54a3537555c11` and Emscripten 5.0.1. Development rebuilds may use Docker; runtime does not.

LGPL/OCCT notices and corresponding pinned source archives accompany the release. To replace/relink the WASM library: obtain the pinned source archives, rebuild the `custom_build_single.yml` target with its documented upstream toolchain, substitute the resulting Replicad module/WASM in `web/node_modules/replicad-opencascadejs`, run the frontend build, then rebuild My3D.exe. Modified compatible library builds may be used for debugging/relinking; My 3D imposes no restriction on that right. All required frontend/server source is published. Font: Abel from Google Fonts, OFL-1.1, included with its notice; icons: Lucide ISC; logo: original SVG. Segoe UI is a system fallback, not redistributed.

One Workspace integration was inspected in its actual `oneworkspacestudio/one-workspace` repository. Standard apphost OIDC Authorization Code + PKCE, token/nonce validation, issuer+subject identity mapping, CSRF, expected-account checks, secure cookie policy, NTFS ownership protection, private logs, encrypted backups and server ownership checks are reused. The page CSP retains strict scripts; only the hashed CAD worker response permits Embind's dynamic binding construction. No browser-side admin credentials or external model asset fetches are allowed. Native uploaded B-Rep/STEP processing remains confined to the browser worker.

Official printer references: [A1 specifications](https://us.store.bambulab.com/products/a1), [A1 mini specifications](https://store.bblcdn.eu/s8/default/87c1a9ef9f3a438a87d8f19fd8faea58/Bambu-Lab-A1-mini-tech-specs.pdf). Profiles are dimensional guards, not connected printers.
